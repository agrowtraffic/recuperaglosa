# RecuperaGlosa — Dashboard completo

Implementação visual em Next.js com todas as abas navegáveis:

- Visão geral
- Lotes
- Guias
- Glosas
- Recursos
- Relatórios
- Configurações
- Modal de novo upload

## Executar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

Os dados são demonstrativos e a navegação funciona inteiramente no front-end. A próxima IA pode conectar as telas às APIs/Supabase sem alterar o design.
