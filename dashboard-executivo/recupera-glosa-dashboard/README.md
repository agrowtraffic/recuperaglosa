# RecuperaGlosa — Dashboard visual completo

Projeto Next.js autocontido para replicar o dashboard e a identidade visual da imagem de referência.

## Executar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Estrutura

- `app/page.jsx`: dashboard, brand board, logo em SVG, abas e componentes.
- `app/globals.css`: medidas, cores, tipografia, espaçamentos, sombras e responsividade.
- `public/reference-dashboard.png`: imagem visual de referência.
- `DESIGN_SPEC.md`: instruções para outra IA preservar fidelidade.

## Observação

O dashboard é totalmente responsivo e não depende de biblioteca de ícones. Todos os ícones e a marca foram desenhados em SVG diretamente no código.
